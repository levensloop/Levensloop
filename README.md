# Levensloop: broncode

Dit is de broncode van Levensloop, je eigen levenssimulatie. Wat je op je iPhone speelt, wordt hieruit gebouwd.

## Waar staat wat

- **De app die je speelt** staat op GitHub in de branch `main`. Die wordt automatisch gemaakt: nooit met de hand aanpassen.
- **Deze broncode** staat op GitHub in de branch `bron` van `levensloop/Levensloop`. Dat is het enige origineel.
- **`VERBETERPLAN.md`** is het plan met alle fasen. Bovenaan staat wat al klaar is.
- **`CLAUDE.md`** is de uitleg voor Claude: hoe de code in elkaar zit, hoe je bouwt en test.

## Een nieuwe chat met Claude op weg helpen

Begin een nieuwe chat en schrijf bijvoorbeeld:

> Ik wil verder met Levensloop. De broncode staat op GitHub in levensloop/Levensloop, branch `bron`. Lees eerst CLAUDE.md en daarna VERBETERPLAN.md.

Lukt het Claude niet om bij GitHub te komen, stuur dan de laatste zip van de broncode mee en schrijf: "Lees eerst CLAUDE.md".

## Handige dingen om te weten

- **Reservekopie:** Menu → Reservekopie. Doe dit af en toe. Als je het app-icoon verwijdert, ben je anders al je levens kwijt.
- **Foutenlog:** Menu → Foutenlog. Gaat er iets mis, maak dan een schermafbeelding van dit scherm en stuur die naar Claude.
- **Meetscherm:** tik vijf keer snel op het versienummer onderaan het menu. Handig als iets niet goed in beeld staat.
- **Nieuwe versie:** na een update zie je bovenin "Nieuwe versie · tik om bij te werken".
